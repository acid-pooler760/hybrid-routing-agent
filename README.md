## 🚀 What is This?

hybrid-routing-agent is a powerful tool that helps computers learn to control software applications automatically. It combines two ways of controlling a computer: direct mouse and keyboard actions (like a person clicking buttons) and smart tool calls (like using special commands). This makes it incredibly useful for automating complex tasks in any software environment.

Think of it as a smart assistant that can watch what happens on your screen and decide whether to click a button or use a built-in command to get things done faster and more accurately.

## 🎯 Key Features

- **Hybrid Control**: Combines direct GUI control (mouse clicks, keyboard typing) with intelligent tool usage
- **Reinforcement Learning**: The system learns from experience to improve its performance over time
- **OSWorld Compatible**: Works with the OSWorld computer-use environment for testing and evaluation
- **Qwen3-VL-8B-Thinking Powered**: Uses advanced AI to make smart decisions about how to control your computer
- **Flexible Setup**: Can be configured for different tasks and environments

## 🔧 Troubleshooting

**Problem**: Application won't start
- **Solution**: Make sure your antivirus software isn't blocking the application. Try running as administrator (right-click > Run as administrator)
